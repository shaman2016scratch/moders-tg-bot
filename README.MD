Это репозиторий с исходным кодом модерс бота.

# Модифицирование

1. Нажимаете кнопку Fork сверху от репозитория или выполняете git clone https://github.com/shaman2016scratch/moders-tg-bot
2. Создаете файл data.json в корне проекта - там будут хранится все данные. Скопируйте templace.data.json и вставте в созданный файл.
3. Создайте .env файл и заполните его.
4. Установите зависимости (npm i)
5. Запустите (npm start)

Внимание: В коде бота нет встроенного прокси для api. Если вы в стране где заблокирован telegram или github, вам нужно проксировать трафик.
